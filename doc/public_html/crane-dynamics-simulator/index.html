Crane Dynamics Simulator

Crane Dynamics Simulator (CDS) is a MATLAB package for simulating mechanical systems.

Systems are described through a declarative interface, and the software then symbolically generates the equations of motion using the Euler-Lagrange formulation with Lagrange multipliers. The software can solve these equations in MATLAB, or export them to C++. Tooling is provided to automatically generate, evaluate, and plot symbolic expressions for physical quantities at a per-system-element level, including trajectories, force decompositions, energy decompositions, and power decompositions.

  • This package does not contain any AI generated content.
  • The design philosophy is to provide automation, not abstraction.
  • The underlying maths and physics are accessible to the user, and are presented in a way that mirrors a pen-and-paper derivation.

Example

This is a complete example. Compare the code to the kinematic diagram (fig1).

The code generates the displayed animation (fig2) and plot (fig3).

Copy/paste it into matlab to solve the double pendulum.

% System parameters
sys = CDS_SystemDescription();
sys.params.Create('free', 'theta_1').SetIC(1); % Generalised coordinate
sys.params.Create('free', 'theta_2').SetIC(0); % Generalised coordinate
sys.params.Create('const', 'L1').SetNum(1);
sys.params.Create('const', 'L2').SetNum(1);
sys.params.Create('const', 'g').SetNum(9.8);

% Forward transformations
T_OA = CDS_T('at',  'z', theta_1);
T_AB = CDS_T('atP', 'z', theta_2, [L1;0;0]);
T_BC = CDS_T('P',                 [L2;0;0]);
T_OB = T_OA * T_AB;
T_OC = T_OB * T_BC;

% Point masses
A = sys.CreatePoint('A');
B = sys.CreatePoint('B').SetT_0n(T_OB).SetMass(1);
C = sys.CreatePoint('C').SetT_0n(T_OC).SetMass(1);

sys.SetGravity([g; 0; 0]); % Direction of gravity
sys.SetChains([A,B,C]); % For the animation

% Solve the system
S = CDS_Solver;
[t,x,xd] = S.Solve(sys);

% Process the results
SS = CDS_SolutionSim(sys, t, x, xd);
SSa = CDS_Solution_Animate(SS);
SSp = CDS_Solution_Plot(SS);

% Plot an animation
SSa.Animate

% Evaluate and Plot Arbitrary symbolic expressions
massPoints = [B;C];
SSp.PlotSymExpr([...
    massPoints.Power_dKdt,...
    massPoints.Power_dVdt,...
    massPoints.Power_dEdt])
legend(["(dKdt) ","(dVdt) ","(dEdt) "] + massPoints.NameReadable,...
    Orientation='horizontal', NumColumns=2, Location='northoutside');

% Generate symbolic expressions per system element
simplify(B.Power_dEdt)
ans =
L1*theta_1d*(L1*theta_1dd + g*sin(theta_1))

Key Capabilities

Modelling Capabilities

Model components can be described by their fundamental properties. For example, a spring can be defined by its length without being attached to a specific location. Likewise, a location can be defined by its transformation, independent of any underlying kinematic linkage.

Components

  • rigid bodies
  • point masses
  • massless locations
  • springs
  • torsion springs
  • dampers
  • point forces
  • generalised forces
  • holonomic constraints

Features

  • explicit time dependence (e.g. rheonomous systems)
  • position-driven coordinates (e.g. servo-controlled)
  • state-dependent forces (e.g. state feedback)
  • Baumgarte stabilisation

Automatic Equation Generation

Equations can be generated in representation of the system as a whole, and as decomposed by system component and degree of freedom.

Decompositions can be split into categorised contributions from inertia, Coriolis and centrifugal effects, explicit time dependence, and velocity dependent potentials.

Whole-system equations

  • System equations (formed as ODEs or DAEs)
  • Euler-Lagrange equations with Lagrange Multipliers
  • Values of Lagrange Multipliers

Derived Quantities

  • Lagrangian
  • Hamiltonian
  • system energies
  • equivalent generalised forces

Decompositions

  • energy balance
  • power balance
  • force balance

Getting Started

The target audience of this software should already be familiar with applying Lagrangian mechanics by pencil-and-paper method to describe and solve simple systems (e.g. a pendulum-cart), and with describing 3D pose using 4x4 homogeneous transformation matrices.

Required Software

  • MATLAB (Tested on version 2025a. Other versions may or may not work)
  • MATLAB Symbolic Math Toolbox
  • MATLAB Robotics System Toolbox
  • MATLAB Curve Fitting Toolbox (Optional - Used for some specific types of input)
  • MATLAB Signal Processing Toolbox (Optional - Used in some input files)

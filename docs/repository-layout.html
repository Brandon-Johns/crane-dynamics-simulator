Repository Layout

The most important part of the simulator is core/CDS/. If you only care about 2 things, it should be this and run_matlab/Examples/.

Simulator

core/ is self-contained. It has no external dependencies, and it does not specify data input/output filepaths. Filepaths are to be specified in function arguments, or default to the working directory. The exception being that the helper CDS_GetDataLocations contains the base paths to the directories in data/. However, this file is not itself used within core.

Within core, core/CDS/ is fully self-contained, while core/Models/ and core/Utilities/ depend on core/CDS/.

Directory Class Prefix Content
core/CDS/CDSThe simulator
core/Models/CDSm, CDSv, CDSvbFrom the related research article:
  • Models (CDSm)
  • Values of parameters and inputs (CDSv, CDSvb)
core/Utilities/CDSuHelpers to format and plot results
core/includes_matlab/CDSHelpers to add the folders in core to the MATLAB path.
Helpers to form filepaths to the locations in data/.

MATLAB Path Helpers

See the how-to guide for automatically including CDS on the MATLAB path.

Directory Content
core/includes_matlab/CDS_IncludeSimulator.mCalling script this includes core/CDS/ on the MATLAB path
core/includes_matlab/CDS_IncludeModels.mCalling script this includes core/Models/ on the MATLAB path
core/includes_matlab/CDS_IncludeUtilities.mCalling script this includes core/Utilities/ on the MATLAB path

Solver Infrastructure for C++ Code Generation (SUNDIALS)

Used when solving with solve mode CDS_Solver.Solve(..., "sundials"). See C++ Code Generation

The CMake/C++ project and related scripts that are used to compile and run generated C++ code.

Directory Content
lib_ubuntu/Dependencies of the CMake project in run_sundials/, if running on Ubuntu
lib_windows/Dependencies of the CMake project in run_sundials/, if running on Windows
run_sundials/Bash and PowerShell scripts to compile and run the generated code
run_sundials/src/The CMake/C++ project that compiles with the generated code
run_sundials/src/SimC3/The C++ code that compiles with the generated code
run_sundials/src/test_armadillo/Test to validate your correct installation of the Armadillo C++ library
run_sundials/src/test_sundials/Test to validate your correct installation of the SUNDIALS C++ library

Run Files

Scripts that run the simulator for different models

Directory Content
run_matlab/Evaluate/Run-files to evaluate the performance of core/CDS
run_matlab/Examples/Sample run-files which depend only on core/CDS
run_matlab/SimC3/From the related research article: Run-files that use core/Models and/or data/experiments_results
run_matlab/Tests/Run-files to automatically validate core/CDS against known physics

Data

Generated code, saved simulation results, saved plots, and cached intermediary data.

Directory Content
data/experiments_results/From the related research article: Raw data from the trials with a UR5 robot
data/matlab_cache/Used by some run-files: Cache of simulation results for batch processing
data/matlab_fig/Used by some run-files: Output path for figures
data/sundials_generated/Cache of generated C++ code. See: C++ Code Generation
data/sundials_results/Holds simulation results of SUNDIALS solved systems. See: C++ Code Generation
